## 📋 Descripción

**FactoryFlow** es un sistema ERP (Enterprise Resource Planning) orientado a empresas manufactureras. Permite gestionar de forma integral el ciclo completo de producción: desde la entrada de materia prima hasta la venta de producto terminado y su impacto financiero.

### Módulos principales

| Módulo | Descripción |
|--------|-------------|
| **Almacén de Materia Prima** | Control de inventario con costo promedio ponderado, umbrales de reorden y trazabilidad de movimientos. |
| **Productos y BOM** | Registro de productos con atributos dinámicos, categorías jerárquicas y recetas de materiales (Bill of Materials). |
| **Centro de Producción** | Órdenes de producción con explosión de materiales, validación de stock y reconciliación estimado vs. real. |
| **Producto Terminado** | Inventario de bienes terminados con referencia de lote y costo unitario real. |
| **Ventas** | Venta de productos terminados o materia prima con deducción automática de inventario. |
| **Finanzas** | Registro de ingresos y egresos, cuentas por cobrar con indicadores de antigüedad. |
| **Inteligencia de Costos** | Dashboard ejecutivo con análisis de costo estimado vs. real, impacto de desperdicio y utilidad neta. |
