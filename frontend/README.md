# 📦 Frontend Project

Este proyecto corresponde al frontend desarrollado en React.

---

## ⚙️ 1. Requisitos previos (OBLIGATORIO)

Antes de ejecutar el proyecto debes instalar:

### 📥 Node.js (incluye npm)

Descarga e instala desde:

👉 https://nodejs.org/

---

### ✅ Versión utilizada en el proyecto

- Node.js: v24.15.0  
- npm: v11.12.1  

---

### 🔍 Verificar instalación

```bash
node -v
npm -v
```

---

## 📥 2. Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
```

---

## 📂 3. Entrar al proyecto

```bash
cd nombre-del-proyecto
```

---

## 📦 4. Instalar dependencias

```bash
npm install
```

---

## ▶️ 5. Ejecutar el proyecto (REACT / VITE)

### 🚀 Comando principal:

```bash
npm run dev
```

📌 Este es el comando correcto para proyectos React con Vite.

---

## 🌐 6. Abrir en el navegador

http://localhost:5173

---

## 📦 7. Build de producción

```bash
npm run build
```

---

## 👀 8. Previsualizar build

```bash
npm run preview
```

---

## 🧹 9. Reset si hay errores

```bash
rm -rf node_modules
rm package-lock.json
npm cache clean --force
npm install
```

---

## 🔧 10. Comandos útiles

```bash
node -v
npm -v
npm list
npm update
npm audit
npm audit fix
```

---

## ⚠️ Notas importantes

- Ejecutar siempre `npm install` al clonar.
- El comando principal es `npm run dev`.
- `node_modules` no se sube al repositorio.

---

## 🛠️ Tecnologías usadas

- React
- Vite
- JavaScript / TypeScript
- CSS / Tailwind
